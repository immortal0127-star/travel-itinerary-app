# 名古屋 + 黑部立山六日遊

手機版旅遊行程 App，適合部署到 GitHub Pages。

## 功能

- 六日行程切換
- 自動計算每日到達、離開、停留與交通時間
- 黑部立山 Day 4 使用固定班次時間表
- 單點 Google Maps、兩點導航、整日路線
- 可複製今日行程
- 支援加入手機主畫面

## GitHub Pages

部署後請在 GitHub repository 的 Settings > Pages 中選擇：

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

設定完成後，首頁會從 `index.html` 載入。
